# Architecture decision records

Architecture decision records (ADRs) preserve decisions that affect how the
project is built, tested, or operated.

## Status values

Use `Proposed`, `Accepted`, `Superseded`, or `Deprecated`. If a later ADR changes
an accepted decision, link the two records in both directions.

## Naming and structure

Name records sequentially as `NNNN-short-title.md` and include:

1. status and date;
2. context;
3. decision;
4. consequences; and
5. alternatives considered.
